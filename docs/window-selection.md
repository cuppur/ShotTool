# 窗口识别与功能范围（0.7.0）

## 操作

按 Alt+A 后，鼠标所指的最上层可见窗口自动显示边框。单击进入编辑，按住拖动改为任意区域框选。

- 预览时滚轮向下选择鼠标下的原生子控件，向上返回父层，默认选整窗。鼠标在同一个控件内移动时保持选定层级。
- 按住 Shift 临时关闭自动识别，松开恢复。已锁定的选区不受影响。
- 锁定后，退出绘图工具可用方向键移动 1 像素，Shift+方向键移动 10 像素。
- Ctrl+A 锁定整个虚拟桌面，之后不会随鼠标重新吸附窗口。

## “精准”的含义与边界

边框数据取自 Windows 的 DWM 可见窗口边界，失败时回退 GetWindowRect；PerMonitorV2 下使用物理像素，不额外乘缩放。最大化窗口裁剪到所属显示器，普通窗口裁剪到虚拟桌面。过滤最小化、隐藏、被系统 cloak 的窗口、完全透明的分层窗口和透明穿透层。自定义 HWND 区域参与鼠标命中判断。

在覆盖层显示前保存窗口和子控件的前后层级。鼠标移动时不调用目标程序，也不使用 OCR 猜测窗口边缘；因此不会因另一个软件无响应而在鼠标路径上等待。子控件按父窗口客户区裁剪，只沿最上层命中的子窗口向下寻找。系统 HWND 枚举有总量和深度上限，达到上限时保留已读取层级。

这能精确选择系统提供边界的整窗、面板、输入框等原生控件，但**不等于识别所有画面中的视觉对象**：

- Chromium/Electron、游戏、视频和其他自绘界面中的图片、聊天气泡、网页卡片常没有独立 HWND，本版不会为这些对象编造框。
- 没有接入 UI Automation、浏览器 DOM 或视觉分割；“控件”只表示原生子窗口。
- 截取的是启动时屏幕上的合成画面，无法还原被前方窗口遮住的内容。
- 自定义软件可能把阴影直接画在自身窗口内部，系统边框无法统一去除这部分像素。矩形选区会包含圆角外的少量背景。
- 截图开始后的窗口移动不会更新这份冻结记录；如屏幕内容已变化，应取消并重新截图。
- 未绕过受保护画面或管理员权限限制。多显示器混合 DPI、HDR 和特殊自绘窗口仍需更多实机验证。

## 与微信、飞书的范围

微信行为基线为项目早期本机 4.1.15.13 的调查，不代表已重新验证 2026-10-24 的最新微信。飞书功能范围参考其[官方截图说明](https://www.feishu.cn/hc/zh-CN/articles/319286513754)。未实测的识别内部机制不作推断。

| 能力 | ShotTool 0.7.0 状态 |
|---|---|
| 无微信或飞书进程、无需登录即可截图 | 已有 |
| 悬停整窗预览、单击锁定、拖动任意框选 | 已有，本版完善边界与过滤 |
| 嵌套原生控件识别 | 已有，滚轮切换层级 |
| 网页图片、卡片、气泡等视觉对象识别 | 未实现，不能承诺与两款客户端等效 |
| 矩形、椭圆、箭头、画笔、文字、序号、马赛克 | 已有 |
| 复制、保存、撤销重做、固定截图 | 已有 |
| OCR 和翻译 | 已有；依赖后端和模型。翻译为文本结果，未实现原位替换 |
| 滚动长截图、水印 | 未实现；飞书官方说明包含这些能力 |
| 自动识别隐私信息并一键打码 | 未实现 |
| 微信/飞书联系人分享、表情等客户端能力 | 未接入 |
| 逐个选择已有标注并重新编辑 | 未实现 |

下一阶段如需覆盖自绘内容，应独立增加有超时和降级能力的 UI Automation 读取；对不提供可访问性信息的应用，再评估视觉区域识别。不能把可靠的整窗识别和所有软件的视觉对象识别视为同一个保证。

## 验证

`ShotTool.exe --selftest-windows` 使用屏幕外、不激活的真实 HWND 测试窗口检查前后层级、窗口和子控件边界、隐藏窗口、自定义形状和冻结记录。通过模拟覆盖层自身事件检查 100% / 225% 缩放、负坐标、单击锁定、滚轮层级、Shift 开关、快速拖动、释放坐标、Ctrl+A 与像素微调。检查不会操纵用户的鼠标。

这不等于已经在微信、飞书、浏览器与所有混合 DPI 设备上人工验收。边界 API 见 [Microsoft DWM 文档](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute)。

## 应用图标

蓝紫色底板、白色框选角和薄荷绿裁切笔画。托盘在小尺寸下省略中央半透明区域。运行时与 exe 的 16–256 像素 ICO 共用 `TrayIconFactory` 的绘制源。

使用 `ShotTool.exe --export-icon` 在 `SHOTTOOL_SELFTEST_DIR` 指定目录输出 `ShotTool.ico`、`app-icon.png`，将 ICO 更新到 `Assets/icons/ShotTool.ico` 后重新构建即可更新 exe 资源。`Assets/icons/shottool.svg` 提供矢量预览。
