# 使用说明

## 截图和标注

运行后在系统托盘常驻。按 Alt+A，拖拽框选区域，点击工具条选择标注工具。

| 操作 | 按键或方式 |
|---|---|
| 开始 / 取消截图 | Alt+A，可在设置中修改 |
| 自动贴合窗口 | 悬停显示窗口边界，单击锁定；按住拖动自由框选 |
| 切换识别层级 | 预览时滚轮向下选择原生控件、向上返回整窗 |
| 临时自由框选 | 按住 Shift 关闭自动吸附，松开恢复 |
| 精细移动选区 | 锁定后方向键 1 像素，Shift+方向键 10 像素，需退出绘图工具 |
| 全屏选区 | Ctrl+A |
| 矩形、椭圆、箭头、画笔、马赛克、文字 | Ctrl+1…6 |
| 切换颜色与线宽 / 字号面板 | Tab，先选工具 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 复制图片 | Enter / Ctrl+C / 完成按钮 |
| 保存图片 | Ctrl+S / 保存按钮 |
| 固定截图 | F3 / 图钉按钮，限当前截图窗口 |
| 取消 | Esc / 右键 |

再次点击已选工具可退出绘图状态，之后可拖动选区。八个控制点用于调整大小。

文字输入直接透出当前截图背景，无白色底板。Enter 确认，Shift+Enter 换行，Esc 取消本次输入。使用文字工具或退出绘图工具后，拖动已有文字可移动位置，双击可重新编辑。点击文字后按 Delete 删除；移动、修改和删除都支持 Ctrl+Z / Ctrl+Y。绿色文字选中边框不会出现在复制或保存的图片里。

## 贴图

固定截图保留标注，截图窗口关闭后仍在桌面置顶。左键拖动，滚轮缩放，双击或 Ctrl+0 恢复大小，Ctrl+C 复制原分辨率图片，Ctrl+S 另存为。Esc、Delete 或右键菜单关闭。退出托盘程序会关闭全部贴图，当前不跨重启恢复。

## 设置

右键托盘图标 → 设置。设置页分为“截图与保存、文字与翻译、常驻、关于”。底部保存和取消始终可见；窗口较小时，页内内容可滚动。保存后应用热键及识别后端配置。

配置位于 `%LOCALAPPDATA%\ShotTool\settings.json`；默认保存位置为“图片”目录下的 ShotTool 文件夹。设置页提供打开配置目录的按钮。

## 登录自启

启用后，单文件发布版会在 `%LOCALAPPDATA%\ShotTool\App\<程序摘要>\ShotTool.exe` 留下独立副本，原下载目录移动、删除或升级不会破坏这份副本。不同版本分目录保留，避免运行中的旧 exe 锁住升级文件。此目录不是截图或翻译模型的存放位置。

优先登记当前用户的 `ShotTool Startup <用户 SID>` 登录任务，不保存密码、不提升权限；登录后延迟 5 秒启动，允许电池供电，不限制后台运行时长，失败时每分钟重试，最多 3 次。系统策略不允许创建任务时回退到 Windows Run 启动项，界面显示实际使用方式。Run 项可能被 Windows 延迟。

在常驻设置里可查看实际状态。用户在系统中禁用任务或启动项后，程序不会在普通启动时擅自重新开启；重新勾选并保存可主动修复。关闭开关会移除自己的登录任务和旧 Run 项。旧版本只登记下载目录里的 exe，0.8.0 在普通启动、原自启仍启用时会迁移；登录任务启动时不反复改登记，也不会因已有实例而弹出截图。

登录任务可在 Windows 任务计划程序中查看。实际重启、退出后重新登录是否能正常启动，仍需在用户下一次登录时确认；离屏检查和任务配置核对不能替代这个场景。

## OCR

系统 OCR 使用已安装的 Windows 识别语言包。Paddle OCR 使用可选内嵌模型。自动模式按选区亮度选择可用引擎。OCR 准确性受字号、字体、背景、方向和排版影响。

识别结果可编辑，可复制或追加到剪贴板。结果框获得焦点时，Ctrl+C / Ctrl+A 用于操作文本。

## 离线翻译

默认关闭翻译。翻译按钮仍可显示配置说明。在设置中启用 NLLB 后，模型优先从程序旁的 `models/nllb-200-distilled-600M-int8/` 查找，也支持用户目录或自定义路径。

需要 `encoder_model_int8.onnx`、`decoder_model_int8.onnx`、`tokenizer.json`；可同时提供 `config.json`。可参考原始模型 [Meta NLLB-200](https://huggingface.co/facebook/nllb-200-distilled-600M) 和转换模型来源 [tfchan-lab ONNX](https://huggingface.co/tfchan-lab/nllb-200-distilled-600M-onnx)。模型不存入本仓库，下载和使用前请核对其模型卡、来源与许可。NLLB 上游标明 CC-BY-NC-4.0，需保留署名，限非商业用途。

翻译通过 OCR 获取原文，当前以中英互译为主，显示文本结果而不覆盖原图。模型仅在使用时加载，空闲 5 分钟后卸载。也保留本机 Ollama 适配，参数在配置文件中管理。

## 已知限制

没有长截图、自动敏感信息打码、表情或微信联系人分享。窗口识别以 Windows 顶层窗口边界为准，不能单独识别窗口内部控件；已有标注不能逐个选中重新编辑。多显示器混合 DPI、HDR、受保护视频和独占游戏画面仍需更多实机验证。程序未做代码签名。
